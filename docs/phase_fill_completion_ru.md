# Инструмент Fill — заливка обведённой области (по отзывам пользователей)

## Что сделано

Новый инструмент **◉ Fill** (`G`): обвести объект — вся обведённая область закрашивается.

- При отпускании кнопки конец контура соединяется с началом прямой (как лассо), внутренность заливается. Во время обводки белый пунктир показывает замыкание.
- Контур **сохраняется сразу** (одна отмена на контур, Enter не нужен) — аннотация сразу в панели Annotations, ✓ у изображения.
- Работает с классами **mask** и **semantic** — одна кнопка, поведение выбирает тип класса:
  - mask — каждый контур = новая маска; при выделенной маске этого класса контур добавляется к ней (та же аннотация, новый PNG-файл ревизии — для отмены); erase вырезает из выделенной маски, без выделения — из всех масок класса, пустая маска удаляется;
  - semantic — контур пишется в слой класса через логику Semantic brush (правило overwrite / keep).
- Параметры: Contour width (радиус линии, 3), Mode draw / erase, Other classes (только semantic).
- Esc во время обводки отменяет контур; клик без движения ничего не создаёт.
- `meta.tool = "fill"`.

### Исправление Brush (найдено при проверке Fill)

Первая версия Fill для mask копила заливки до Enter, как Brush. При проверке выяснилось, что это неочевидно, а Brush вдобавок **терял работу**: инструмент не узнавал о смене изображения —

- незафиксированные мазки молча пропадали при смене инструмента и оставались на холсте при переходе к другому изображению (Enter записал бы их туда);
- маска, загруженная для правки (выделить → M), при переходе к другому изображению исчезала со своего и при смене инструмента записывалась на чужое.

Теперь:
- контроллер шлёт `image_about_to_change` перед уходом с изображения (смена изображения, открытие / создание / закрытие проекта, закрытие окна) — пока текущим ещё остаётся старое изображение; главное окно вызывает `leave_image()` активного инструмента (новый необязательный метод `BaseTool`);
- Brush по `leave_image()`, смене инструмента и смене класса сохраняет изменённые мазки (с классом, которым рисовали); загруженная, но не изменённая маска возвращается как была (тот же id и файл); Esc по-прежнему сбрасывает;
- после первого мазка в строке состояния: «маска ещё не сохранена — Enter = сохранить · Esc = отменить».

### Исправление отображения масок (найдено при второй проверке)

Вырезанная заливкой (или кистью) дырка сохранялась в PNG, но на холсте не появлялась: `MaskAnnotationItem` рисовал только `polygon` — внешний контур самой большой области. Теперь маска рисуется из PNG (`load_mask_cached`, общий кэш цветных pixmap с семантическими слоями), обводка — все внешние контуры и контуры дырок (`RETR_CCOMP`, кэш по пути файла), попадание мышью — по пикселям. Без PNG — прежний вывод по полигону.

## Устройство

- `annotator/tools/fill_tool.py`:
  - `fill_enclosed(contour)` — заливка от рамки вокруг изображения (`cv2.floodFill`, 4-связность), всё недостижимое снаружи = внутри контура;
  - `_Contour` — пиксели линии, превью-путь, пунктир замыкания, признак «было движение»;
  - `_MaskFill` — сохраняет контур сразу (`edit_group`, `update_annotation_data` с `MaskStorage.save_mask(revision=True)`);
  - `_SemanticFill(SemanticBrushTool)` — коммит слоя;
  - `FillTool` — фасад: делегат выбирается в `set_class()`.
- `MaskStorage.save_mask(..., revision=True)` — новое имя файла для правки существующей маски.
- `ProjectController.image_about_to_change`, `leave_current_image()`; `BaseTool.leave_image()`; `MainWindow._on_image_leaving`.
- `BrushTool`: `_dirty`, `_save_pending()`, `leave_image()`, `_ensure_canvas()` (холст под размер нового изображения), подсказка `brush_unsaved` (i18n EN/RU).
- `ANNOTATION_TYPE_TOOLS`: mask → brush, fill; semantic → semantic_brush, fill (инструменты по умолчанию прежние).
- Горячая клавиша `tool_fill = G` (Project Settings), меню Tools, кнопка на панели, подсказка в тулбаре EN/RU.

## Ограничения

- YOLO Seg и LabelMe по-прежнему получают один внешний контур маски (без дырок и мелких кусков) — ограничение этих форматов; COCO, Panoptic, Semantic Masks берут PNG целиком.
- Дырку «бублика» заливка сама не оставляет — вырезается вторым контуром в режиме erase.
- Край изображения не замыкает контур (контур ведётся за край — точки прижимаются к краю).
- Shift+клик прямыми линиями в Fill нет.
- Чтобы дорисовать маску заливкой, её надо выделить заранее (Select или панель Annotations) — щелчок по холсту в режиме Fill выделения не меняет.
- Brush при смене класса сохраняет мазки со старым классом (раньше молча сбрасывал); загруженная и изменённая маска при этом получает старый класс — как и раньше по Enter.
- Незавершённые построения других инструментов (полигон в процессе и т. п.) при смене изображения по-прежнему просто сбрасываются — `leave_image()` пока реализован только у Brush и Fill.
