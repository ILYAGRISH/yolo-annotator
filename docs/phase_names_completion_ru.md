# Одинаковые имена файлов в разных папках (по отзыву с Habr)

## Проблема

Читатель нашёл: COCO Panoptic складывает изображения в плоские папки по имени файла, и `road_a/frame.jpg` с `road_b/frame.jpg` затирают друг друга. Проверка показала, что хуже: **сам проект** хранил разметку в `annotations/<имя без расширения>.json` — у одноимённых изображений был один файл, рамка с одного появлялась на другом. Плоские имена использовали все форматы экспорта, назначения разметчикам, список изображений и импорт YOLO.

## Что сделано

- **Ключ изображения** `ImageRecord.key` — уникальное в проекте имя (без учёта регистра): имя файла, а при повторе `<папка>_<имя>` (`road_b_frame`), затем `_2`, `_3` (`domain/project.py`: `unique_stem`, `Project.add_image / image_key / ensure_image_keys`). В `images.json` пишется только у переименованных — файлы проектов без повторов не меняются.
- **Хранилище**: `annotations/<ключ>.json` (`ProjectStore.load/save_annotations`, `load_all_annotations`).
- **Старые проекты**: при открытии одноимённые изображения получают ключи (первое сохраняет имя), каждому переименованному копируется прежний общий файл (существующий файл нового имени не трогается), ключи сразу сохраняются, окно «Изображения с одинаковыми именами» перечисляет их.
- **Экспорт**: `exporters/base.export_name()` — во всех форматах (YOLO все виды и multi-task, COCO, COCO Keypoints, COCO Panoptic, LabelMe, Pascal VOC, Semantic Masks, YOLO Classify) имя файла = ключ + исходное расширение; разметка / маска / XML / записи JSON — с тем же именем. Без повторов имена прежние.
- **Интерфейс**: в списке у переименованного видна папка (`road_b/frame.jpg`); ✓ и 🤖 по ключу; назначения разметчикам и фильтр клиента — по ключам (старые `assignments.json` совместимы: у уникальных ключ = прежнее имя); окно назначений показывает дубликаты отдельно.
- **Импорт YOLO**: изображение ищется по пути; по имени — только если в проекте ровно одно такое (иначе добавляется новое, а не угадывается).

Почему не патч из отзыва (`{img_id}_` перед каждым именем): он чинил один формат, переименовывал все файлы даже без повторов и не помогал, потому что разметка была слита ещё в проекте.

## Не менялось

- Автоэкспорт YOLO рядом с изображениями (`labels/` возле папки картинок) — там имена локальны для папки, по правилам YOLO.
- MOT (кадры нумеруются), Video Events (кадры по папкам видео).
- Имена PNG-масок уже были уникальны (id аннотации / ревизия).

## Ограничения

- Уже смешанную разметку старого проекта автоматически не разделить — получают копию, лишнее удаляется руками.
- При экспорте без копирования изображений переименованное имя (`road_b_frame.jpg`) в JSON / XML не существует на диске — с повторяющимися именами экспортируйте с копированием.
- Прежние версии программы, открыв новый проект, снова увидят у одноимённых один файл (поле `key` им неизвестно).
