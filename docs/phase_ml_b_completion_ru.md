# Фаза 7-B — предразметка YOLO-моделью: отчёт

## Итог

Своя (или любая Ultralytics) YOLO-модель размечает текущее изображение (`Ctrl+L`) или весь датасет (**ML → Разметить датасет моделью…**, `Ctrl+Shift+L`). Поддержаны все пять типов моделей: detect, segment, obb, pose, classify. Классы модели сопоставляются с классами проекта автоматически по имени, вручную в таблице или создаются одной кнопкой. **Тип класса проекта решает геометрию**: модель сегментации заполняет и полигоны, и маски кистью; детектор — рамки, OBB, точки. Аннотации модели помечены в панели **🤖 0.87**, удаляются отдельной командой. Скорость — ~25 мс на изображение (RTX 5060 Ti, yolo11n-seg), включая протокол.

Принятые решения (по ответам пользователя): пометка модельной разметки в панели аннотаций; недостающие классы — предлагать создать.

## Доработки по итогам ручной проверки

- **Поиск** над таблицей классов модели (по имени и номеру).
- Классы создаются кнопками **сразу**, а не только при запуске разметки — видны в панели классов: «+ новый класс» в строке — отметка, **«Создать выбранные»** создаёт отмеченные, **«Создать все недостающие»** — все пропущенные и отмеченные (с учётом поиска; больше 10 — с подтверждением). Отмеченные, но не созданные классы создаются при запуске.
- В списке строки классы, уже выбранные в других строках, — в конце под заголовком «уже выбраны для других классов модели» (выбрать можно, но не путаются).
- **Класс `object` нового проекта** (единственный, без разметки, ни на что не сопоставлен) заменяется первыми созданными классами — номера начинаются с 0. Раньше он оставался, а удалить последний класс из схемы нельзя. Константа `DEFAULT_CLASS_NAME` в `domain/project.py`.

## Как устроено

```
PrelabelDialog / Ctrl+L                   (annotator/ml)
   └─ PrelabelRunner: по одному изображению ──► yolo.predict (ml_backend, пиксели)
         └─ convert.convert(): пиксели → нормализованные Annotation по типу класса
               └─ controller.apply_annotation_changes(image, add, remove)
                     текущее изображение → один шаг undo;  остальные → диск + labels/
```

- **Один запрос на изображение**, следующий — после ответа: отмена мгновенная, результаты пишутся по мере поступления (остановленный прогон сохраняет сделанное), ошибка одного изображения не останавливает прогон, падение сервера — останавливает.
- **Сервер отдаёт пиксели** исходного изображения; маски — в полном разрешении (`retina_masks`), контур каждой части отдельно (`masks.xy` Ultralytics склеивает части перемычками — не используем). Изображение читается через `np.fromfile + imdecode` (кириллица в путях Windows).
- **OBB**: `xywhr` в пикселях → `cx/W, cy/H, w/W, h/H, angle_deg` — ровно как хранит холст (ширина по ширине, высота по высоте, поворот в пикселях, ось Y вниз).
- **Модель ищет только сопоставленные классы** (`classes=` в predict) — быстрее и без лишнего.
- **Режимы для изображений с разметкой**: пропускать (по умолчанию) / заменять прежнюю разметку модели (ручная остаётся) / добавлять.
- **Создание классов** — одним сохранением и одним `project_changed` (модель COCO — 80 классов); поза с 17 точками получает имена и скелет COCO.
- **Настройки** — `<project>.annproj/ml_prelabel.json`: последняя модель, пороги, режимы, сопоставление классов для каждой модели.

## Риски и ограничения

- Разметку всего датасета не отменить через Ctrl+Z (стек отмены — только текущее изображение); есть команда «Удалить разметку модели», и режим по умолчанию «пропускать» не трогает размеченное.
- 🤖 значит «создано моделью», а не «не проверено»; статуса «проверено» нет. На холсте аннотации модели не выделены.
- Маски из сегментации — без дырок (внешний контур каждой части); полигон — только крупнейшая часть объекта.
- Классы `polyline` и `semantic` моделью не заполняются; классификация — только top-1.
- Уверенность не экспортируется.

## Найдено попутно (не исправлено — вне фазы)

**Экспорт YOLO OBB для неквадратных изображений.** `exporters/yolo_obb.py::_format_obb` поворачивает углы рамки в **нормализованных** координатах, а холст хранит `w` по ширине, `h` по высоте и поворачивает в **пикселях**. Для повёрнутой рамки на неквадратном снимке экспортированные углы не совпадают с нарисованными. Исправление: считать углы в пикселях (размеры изображения есть в `ImageRecord`) и нормализовать после поворота; то же проверить в автоэкспорте `labels/` (использует `_format_obb`).

**Номера классов YOLO с пропусками.** Метки YOLO пишут `class_id` как есть, а `data.yaml` перечисляет `names` подряд по возрастанию id. Если из схемы удалён класс **в середине** (id 0, 1, 2 → удалён 1 → остались 0, 2), `nc: 2`, а в метках встречается `2` — номер за пределами списка, имена сдвигаются. Исправление: при экспорте YOLO переводить id в порядковый номер (или уплотнять id при удалении класса с переписью аннотаций).
