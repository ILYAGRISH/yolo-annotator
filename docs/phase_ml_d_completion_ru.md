# Фаза 7-D — SAM по рамкам: отчёт

## Итог

Две возможности на одной новой функции сервера `sam.boxes` (много рамок одного изображения → по маске на каждую, за один проход):

1. **ML → Рамки → контуры через SAM…** — уже существующие рамки класса (`bbox` / `obb`, нарисованные вручную или детектором) превращаются в полигоны, маски кистью или плотные повёрнутые рамки другого класса: текущее изображение, все или сплит. Целевой класс можно создать прямо в окне («+ новый класс «car_polygon» / «car_mask»»); по умолчанию выбирается класс с похожим именем, никогда — посторонний. Рамки остаются или удаляются. Повторный запуск в тот же класс пропускает уже обведённые рамки (`meta.from_box`).
2. **«Контуры через SAM»** в окне предразметки (только для моделей-детекторов): рамки, идущие в классы `polygon` / `mask` / `obb`, обводятся SAM — обычный детектор (например, `best.pt`) заполняет классы сегментации настоящими контурами. Работает и для `Ctrl+L`; в итоге — «из них обведено SAM — N».

Результаты обоих — аннотации модели (🤖, уверенность — оценка качества маски SAM).

Скорость (RTX 5060 Ti, `sam2.1_b.pt`): 3 рамки — 44 мс + кодирование изображения ~0,5 с. Реальный прогон `yolo11m` + SAM на `bus.jpg`: автобус (маска) и 4 человека (полигоны по фигуре) — 5 объектов за 4,4 с вместе с запуском сервера и загрузкой обеих моделей.

## Как устроено

```
SamBoxesDialog ─► SamBoxRunner: по изображению ─► sam.boxes(все рамки класса) ─► convert(task=segment)
PrelabelRunner: yolo.predict ─► (детектор + галочка) sam.boxes(рамки polygon/mask/obb-классов) ─► convert
```

- `sam.boxes` — рамки пачками по 32 (память видеокарты), ответ в том же порядке; пустой результат, если SAM ничего не нашёл (рамка остаётся как есть / прямоугольник в предразметке).
- OBB-класс: `min_area_rect` (перенесена в `convert.py`, общая с инструментом SAM).
- Рамка OBB в запросе — описанный прямоугольник её углов, повёрнутых в пикселях (как на холсте).

## Доработки по итогам ручной проверки

- **«+ новый класс» с выбором типа**: для детектора — bbox / polygon / mask / obb, для сегментации — polygon / mask / bbox (раньше — только тип по умолчанию, у детектора bbox). Для детектора с polygon / mask / obb без «Контуры через SAM» под галочкой — подсказка.
- **Тип класса в редакторе схемы можно менять, пока у класса нет аннотаций** (и он не получает аннотации удаляемого класса); при удалении класса передать аннотации можно только классу того же типа. Правило из дорожной карты («тип неизменяем») ослаблено — оно защищало разметку, а у пустого класса защищать нечего.

## Риски и ограничения

- Контуры — внешние, без дырок; полигон — крупнейшая часть объекта.
- Удаление рамок на других изображениях не отменяется `Ctrl+Z` (как вся пакетная разметка) — по умолчанию рамки остаются.
- «Контуры через SAM» удваивает время предразметки на изображение (ещё одно кодирование SAM).
- Если SAM в рамке ничего не нашёл, в предразметке остаётся прямоугольник (полигон/маска по рамке).
