# Фаза 7-C — SAM: разметка кликом: отчёт

## Итог

Новый инструмент **✧ SAM** (`I`, также **ML → SAM — разметка кликом**): левый клик по объекту → маска-превью, правый клик — «не объект», протянуть — рамка-подсказка, `Backspace` — отменить клик, `Esc` — сбросить, **`Enter`** — принять в текущий класс (один шаг `Ctrl+Z`). Тип класса решает результат: полигон, маска кистью, рамка, **повёрнутая** рамка (по минимальному прямоугольнику маски), точка. Модель — любая SAM / SAM 2.x / MobileSAM в формате Ultralytics (по умолчанию рекомендуется `sam2.1_b.pt`), без новых зависимостей.

Скорость (RTX 5060 Ti, `sam2.1_b.pt`): изображение кодируется один раз при открытии (~0,3–0,5 с вместе с прогревом), каждый клик — **16–25 мс**.

## Как устроено

```
SamTool (annotator/ml/sam_tool.py)          ML-сервер (ml_backend/handlers/sam.py)
  открыто изображение ── sam.set_image ──►   кодирование изображения + прогрев декодера (1 раз)
  клик / рамка        ── sam.predict ───►    только декодер по точкам/рамке → полигоны в пикселях
  Enter ── convert.convert(..., tool="sam", source="manual") ── controller.add_annotation
```

- **Один запрос в полёте**: клики, сделанные пока SAM считает, объединяются в следующий запрос; ответы для уже закрытого изображения игнорируются.
- **Кэш на сервере**: модель (путь + mtime) и закодированное изображение (путь + mtime); первый запуск декодера медленный (~250 мс) — он делается при кодировании, а не на первом клике.
- **Перевод маски в аннотацию** — тот же `convert()`, что у предразметки YOLO (две новые опции: `tool`, `source`). Аннотации SAM — **ручные** (`source: "manual"`, `tool: "sam"`): без 🤖 и без уверенности — объект выбрал человек.
- **Правый клик только уточняет**: пока нет левого клика или рамки, запрос не отправляется (иначе SAM угадывал бы объект по одной «отрицательной» точке), внизу подсказка.
- **OBB** — `cv2.minAreaRect` по контуру маски → `[cx, cy, w, h, angle]` в той же системе, что у OBB-моделей.

## Изменения в основной программе (минимальные, общие)

| Где | Что | Зачем |
|---|---|---|
| `MainWindow` | `register_tool(tool, text, shortcut)`, `activate_tool(name)` | расширение добавляет инструмент на панель и в меню Tools, как плагин |
| `MainWindow._enforce_class_tool` | инструменты-плагины не переключаются при выборе класса | SAM сам проверяет тип класса |
| `MainWindow._on_delete_key`, `AnnotationsPanel.delete_selected()` | `Delete` удаляет выделенную в панели аннотацию при любом инструменте (раньше — только с Select) | найдено при проверке SAM |

Всё остальное — в `annotator/ml/` и `ml_backend/handlers/sam.py`. Без ML-окружения кнопка SAM есть, но при клике подсказывает настроить ML.

## Проверено

- Все 14 наборов тестов (791 проверка); новый — 38/38 (+2 с реальной моделью: клик по автобусу — одна большая маска; повторный запрос по тому же изображению без перекодирования).
- Реальный прогон в окне (`bus.jpg`): клик по автобусу + правый клик по человеку → маска автобуса без людей перед ним, 25 мс; Enter → полигон 195 точек в классе `bus [polygon]`; клик по человеку в классе `person [mask]` → маска кистью.

## Риски и ограничения

- Маска — внешний контур, без дырок; полигон — крупнейшая часть (как у предразметки).
- Классы `keypoints`, `semantic`, `polyline` SAM не заполняет.
- На CPU кодирование изображения — секунды (рекомендуется `sam2.1_t.pt`).
- SAM 3 и FastSAM не поддерживаются (другие классы моделей Ultralytics).
- `Enter` / `Backspace` доходят до инструмента, когда фокус на холсте (как у Polygon).
