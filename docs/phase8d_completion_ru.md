# Фаза 8-D — события по времени на видео: отчёт

## Итог

На видео теперь можно отмечать не только объекты, но и **события**: «с кадра A по кадр B — событие X». Пример: перестроение, остановка, обгон, падение, гол. Такая разметка нужна:
- для распознавания действий (temporal action localization);
- для поиска моментов в видео;
- для подсчёта событий.

**Как отмечать.**
- **`E`** на первом кадре и **`E`** на последнем. Можно закончить и на более раннем кадре: границы сами встанут по порядку. Два `E` на одном кадре дают событие в один кадр.
- **`Shift+E`** отменяет начатое событие.
- **Типы событий** общие для всех видео проекта, у каждого своё название и цвет.
  - Новый тип: пункт «+ Новый тип события…» в списке под лентой. Если типов ещё нет, программа сама спросит название при первом событии.
  - Полное управление: **Видео → Типы событий…** (добавить, переименовать, цвет, удалить).
- **Связь с объектом.** Если перед первым `E` выделена аннотация трека, событие относится к этому объекту (`#12`).

**Где видно.**
- **Полоса событий** под лентой кадров.
  - Каждое событие — цветной отрезок с названием, пересекающиеся события лежат в разных строках.
  - Начатое событие заштриховано до текущего кадра.
  - Клик выбирает событие и переходит к кадру, двойной клик открывает правку, при наведении есть подсказка.
- **Строка «Событие:»** с выбором типа. Рядом число событий, события на текущем кадре и красная надпись про начатое событие.
- **Вкладка «События»:**
  - список: тип, кадры, время, трек, заметка; события на текущем кадре выделены жирным;
  - двойной клик переходит к началу события;
  - кнопки «⇤ Начало здесь» / «Конец здесь ⇥», «Изменить…» (тип, кадры, объект, заметка), «Удалить» (или `Delete` в списке), «Типы…».
- **Видео → Предыдущее / Следующее событие.**

**Отмена.** Добавление, правка и удаление отменяются `Ctrl+Z`, пока вы на том же кадре, как и аннотации.

**Экспорт: Video Events (CSV + ActivityNet JSON).**
- `events.csv`;
- `activitynet.json` — формат ActivityNet 1.3, отрезки в секундах, subset по сплиту кадров видео;
- `event_types.txt`;
- с галочкой «Copy videos and frames…» — `videos/` (исходные видео) и `frames/<видео>/` (кадры). Галочка «Skip unreviewed» для этого формата скрыта.

**Правка после проверки:** изначально экспорт событий игнорировал галочку «Copy images», и в папке были только текстовые файлы. Теперь она копирует видео и кадры и для этого формата называется по-другому.

## Как устроено

```
E ─► EventManager.start_here (open_start = кадр, open_track = трек выделенной аннотации)
E ─► finish_here ─► EventChangeCmd (QUndoCommand) ─► _raw_swap ─► events/<видео>.json
лента / вкладка ◄── EventManager.changed;  смена видео ◄── VideoManager.index_changed
```

- **`domain/events.py`** — данные, без Qt:
  - `EventType`, `VideoEvent` (`start` и `end` — кадры исходного видео включительно);
  - `pack_lanes` раскладывает пересекающиеся события по строкам;
  - `seconds`, `time_text`.
- **Хранение.**
  - Типы лежат в `project.json` (`event_types`). Старые проекты открываются без изменений.
  - События лежат в `events/<код видео>.json`, по файлу на видео, как аннотации — по файлу на изображение. Файл пишется сразу после каждого изменения.
- **`video/events.py` — `EventManager`.** Отвечает за:
  - события текущего видео (загружаются при переходе на кадр другого видео);
  - начатое событие, выбранный тип, выделенное событие;
  - команды и типы.
- **Отмена.** Все изменения событий идут одной командой `EventChangeCmd`, где `before` → `after` означает добавление, правку или удаление. Команда лежит в общем стеке отмены, который очищается при смене изображения. Удаление типа не отменяется (с подтверждением) и очищает стек.
- **`video/events_ui.py`** — интерфейс:
  - вкладка `EventsPanel`;
  - окно события `EventDialog`;
  - окно типов `EventTypesDialog`;
  - `ask_new_type` — запрос названия нового типа.
- **`video/timeline.py`** — добавлены полоса `_EventBar` (координаты совпадают с лентой кадров), строка выбора типа и `event_text` для подсказки.
- **`exporters/video_events.py`** — экспорт.

## Риски и ограничения

- **Точность границ.** Границы ставятся на извлечённых кадрах: при шаге 5 точность — 5 кадров видео. Номер кадра можно поправить вручную в «Изменить…».
- **Отмена.** `Ctrl+Z` работает только на текущем кадре: стек отмены общий с аннотациями и очищается при смене кадра. Удаление типа не отменяется.
- **Многопользовательский режим.** Файл событий видео общий: при одновременной правке двумя людьми сохранится последняя. Ограничение «только свои изображения» на события не распространяется.
- **Без автоматики.** События пока ставятся только вручную: нет распознавания событий моделью и нет импорта ActivityNet.
